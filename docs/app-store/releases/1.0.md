## 2.1(a) 반려와 대응

> We are unable to successfully access all of the app. In order for us to
> continue the review, we need sample files to verify all of the app features
> and functionality. ... The sample files you provide should be hosted at a
> location that will remain available for future reviews

원인은 심사 메모에서 심사관에게 터미널로 python 명령을 실행해 자소분리 파일을 직접 만들라고 한 것이다. 이 앱이 고치는 문제는 Finder에서 보이지 않는다. NFD 이름도 Finder는 정상으로 그린다. 그래서 파일을 미리 만들어 주지 않으면 심사관은 아무것도 확인할 수 없다.

대응으로 `docs/app-store/moa-review-samples.zip`을 만들었다.

```
READ ME FIRST.txt                 영어 안내, 검증 명령 포함
1 - Drag these onto Moa/          NFD 파일 3개 + NFD 하위 폴더
2 - Drag this ZIP onto Moa/       Finder 압축 방식 ZIP (__MACOSX 4개, NFD 4개)
```

폴더 이름은 영어로 두고 안쪽 파일만 한글 NFD로 했다. 심사관이 폴더를 탐색할 수 있어야 하기 때문이다. ZIP 왕복 후에도 NFD 5개가 보존되는 것과, 안쪽 ZIP이 실제로 정리 대상(UTF-8 플래그 없음, 맥 전용 항목 4개)인 것을 실측했다. 심사 메모 전문은 `store.config.json`의 `review.notes`에 있다.
