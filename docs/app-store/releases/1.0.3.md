## 원인

콘솔 등록정보는 처음부터 ko 하나였다(기본 언어 `ko`, 이름·부제·설명 한국어). 그런데 iTunes lookup의 `languageCodesISO2A`가 `["EN"]`이었다. 스토어의 "언어" 항목은 콘솔 문구가 아니라 앱 번들에서 정한다. 1.0.2까지 번들은 다음과 같았다.

- `CFBundleDevelopmentRegion = en`, `CFBundleLocalizations` 없음
- `.lproj` 폴더 없음 — 화면 문구가 코드에 한국어로 직접 들어 있다
- Xcode 프로젝트 `developmentRegion = en` (XcodeGen 기본값)

## 바뀐 것

- `project.yml`: `options.developmentLanguage: ko`, Info.plist에 `CFBundleDevelopmentRegion: ko`, `CFBundleLocalizations: [ko]`.
- `MoaApp/Moa/Resources/ko.lproj/InfoPlist.strings` 추가. 앱 이름은 Moa 그대로.

소개 문구(whatsNew):

> App Store에 앱 언어가 영어로 표시되던 것을 한국어로 바로잡았어요. 기능은 그대로예요.

## 확인한 것

- 서명 없는 Release 빌드: Info.plist `ko`·`[ko]`, `ko.lproj` 포함. 실행해 창과 안내 문구가 그대로 뜨는 것을 확인했다. 시스템 요소 이름이 한국어("닫기 버튼")로 바뀌었다.
- `Scripts/release-mas.sh`: 서명·프로파일·Universal·버전 1.0.3 (5)·후원 링크 없음, `altool --validate-app` 통과. 아카이브에도 같은 값과 `ko.lproj`.
- 콘솔: whatsNew·프로모션 텍스트 입력, 빌드 5 연결, `Scripts/asc.py diff --version 1.0.3` 전부 일치.
