## 바뀐 것

- 앱 아이콘이 Icon Composer 원본(`Moa.icon`)에서 빌드된다 (#5). 1.0은 아이콘 이름이 맞지 않아 actool이 `.icon`을 건너뛰고 미리 렌더한 `AppIcon.icns`를 썼다. 그래서 macOS 26 이상의 다크·투명·틴트 모드가 적용되지 않았다.
- 꽃 문양을 꽃술·꽃잎·잎 세 그룹으로 나눴다. 바탕은 비트맵 대신 위에서 아래로 흐르는 선형 그라데이션 채우기로 바꿨다. 다크 모드에서는 시스템 방식대로 바탕이 검게 바뀐다.

소개 문구(whatsNew):

> 앱 아이콘을 새로 다듬었어요. macOS 26 이상에서는 다크 모드와 아이콘 색상(틴트·투명) 설정에 맞춰 아이콘이 바뀌어요.

## 확인한 것

- `Scripts/release-mas.sh`: Apple Distribution 서명, 프로파일 임베드, Universal(x86_64·arm64), 버전 1.0.1 (3), 후원 링크 없음, `altool --validate-app` 통과.
- 아카이브: `codesign --verify --deep --strict` 통과. entitlements는 app-sandbox, user-selected.read-write뿐(1.0과 같음). Assets.car에 Aqua·DarkAqua·Tintable IconImageStack과 평면 아이콘 7개.
- 콘솔: 버전 생성 시 설명·키워드·스크린샷 3장·심사 정보는 1.0에서 복사됐고, 프로모션 텍스트는 복사되지 않아 config 값으로 다시 넣었다. 빌드 연결 후 `Scripts/asc.py diff --version 1.0.1` 전부 일치.
- 아이콘 렌더: ictool로 6가지 모드, 서명 없는 Release 빌드를 NSWorkspace로 그려 확인했다.

## 확인하지 못한 것

- Mac App Store 서명 빌드의 실행. Apple Distribution 서명 앱은 스토어나 TestFlight를 거치지 않으면 로컬에서 실행되지 않는다. 코드 변경이 없어 같은 커밋의 Developer ID 빌드(아래) 실행으로 대신했다.
- macOS 13–15에서 평면 아이콘이 어떻게 보이는지.
