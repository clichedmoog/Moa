## 바뀐 것

- `CFBundleDocumentTypes`에 `public.zip-archive`를 `LSHandlerRank: Alternate`, 역할 Viewer로 추가했다. 기존 `public.item`(Rank None) 선언은 Dock 드롭용으로 그대로 둔다.
- 1.0.1까지는 모아가 어떤 파일의 "다음으로 열기"에도 나오지 않았다. 서비스 ▸ 모아쓰기는 zip에서도 나왔지만 하위 메뉴 안이라 찾기 어려웠다.

> Finder에서 ZIP 파일을 오른쪽 클릭하고 "다음으로 열기"에서 모아를 고르면 바로 ZIP 정리를 시작해요. 더블클릭하면 지금처럼 압축이 풀려요.

## 확인한 것

- 서명 없는 Release 빌드(1.0.2 (4))를 Launch Services에 등록하고 `NSWorkspace.urlsForApplications(toOpen:)`으로 확인했다. zip에서는 모아가 목록에 들어가고 기본 앱은 아카이브 유틸리티 그대로였다. txt와 폴더는 변화 없음.
- 그 빌드로 zip을 열면 `application(_:open:)` → Dock 드롭과 같은 경로로 정리 모드에 들어가 저장 패널이 뜬다. 저장하지 않고 취소했다.
- 임시 폴더(`/private/tmp`) 안의 앱은 Launch Services가 `in-temp-dir`로 표시하고 "다음으로 열기"에서 뺀다. 처음 확인이 실패한 원인이 이것이었다. 저장소 `.build` 아래로 옮겨 확인했다.
- `Scripts/release-mas.sh`: 서명·프로파일·Universal·버전 1.0.2 (4)·후원 링크 없음, `altool --validate-app` 통과. 아카이브 Info.plist에 zip 선언, entitlements는 1.0.1과 같음.
- 콘솔: 버전 생성 후 whatsNew·프로모션 텍스트 입력, 빌드 4 연결, `Scripts/asc.py diff --version 1.0.2` 전부 일치.

## 확인하지 못한 것

- Mac App Store 서명 빌드에서 Finder 메뉴로 직접 고르는 동작. 승인 후 설치본으로 확인한다.
- GitHub DMG 1.0.2는 아직 만들지 않았다.
