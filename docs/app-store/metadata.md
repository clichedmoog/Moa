# Mac App Store 메타데이터 초안

App Store Connect에 붙여 넣을 문구를 여기서 관리한다. 심사 반려로 문구를 고칠 때
무엇을 왜 바꿨는지 남기려고 저장소에 둔다.

## 왜 문구에 공을 들이는가

이 앱은 발견 가능성이 곧 배포다. "자소분리", "한글 파일명 깨짐"으로 검색하는
사람에게 걸리지 않으면 아무도 이 앱의 존재를 모른다. GitHub Release는 이미
저장소를 찾은 사람에게만 닿는다.

ASO 가중치는 **이름 > 부제 > 키워드** 순이라, 검색어를 이름과 부제에 먼저 넣고
남는 것을 키워드 필드로 넘긴다. 키워드 필드에 이름·부제에 이미 쓴 단어를 다시
넣는 건 낭비다.

## 이름 (30자 제한)

```
모아 - 한글 파일명 복구
```

## 부제 (30자 제한)

```
자소분리 고치고 윈도우용 ZIP까지
```

## 키워드 (100자 제한, 쉼표 구분·공백 없이)

```
자소분리,자모분리,깨짐,글자깨짐,파일이름,이름복구,압축,zip,윈도우,전송,인코딩,utf8,NFC,NFD,유니코드,정규화,외장하드,폴더,파일관리
```

이름·부제에 이미 들어간 "모아 / 한글 / 파일명 / ZIP"은 키워드에서 뺐다.
Apple은 이름·부제·키워드를 합쳐서 색인한다.

## 설명

```
맥에서 만든 파일을 다른 사람에게 보냈더니 이름이 깨져서 왔다는 말, 들어본 적 있으신가요?

macOS는 한글 파일명을 유니코드 NFD(풀어쓰기) 형태로 저장합니다. 맥에서는 Finder가
알아서 모아 그려주기 때문에 티가 나지 않습니다. 문제는 파일이 맥 밖으로 나가는
순간에만 드러납니다.

■ 파일을 그대로 보내면
받는 쪽(윈도우)에는 "ㅅㅏㅈㅣㄴ ㅁㅗㅇㅡㅁ.zip"처럼 자모가 흩어져 보입니다.

■ Finder에서 "압축"해서 보내면
더 나쁩니다. macOS 기본 압축은 ZIP의 UTF-8 표시를 세우지 않아서, 윈도우 탐색기가
이름을 CP949로 잘못 읽습니다. 자모가 흩어지는 정도가 아니라 아예 읽을 수 없는
글자가 됩니다.

모아는 이 두 가지를 모두 해결합니다.


▷ 하는 일

• 이름 고치기
  파일이나 폴더를 창에 끌어다 놓으면 이름을 NFC(모아쓰기)로 되돌립니다.
  폴더는 안쪽까지 훑고, 이미 온전한 이름은 건드리지 않습니다.

• 윈도우에서 안 깨지는 ZIP 만들기
  이름을 고친 뒤 UTF-8 표시를 세운 ZIP으로 내보냅니다. macOS가 끼워 넣는
  __MACOSX, .DS_Store 같은 군더더기도 함께 뺍니다.

• 기존 ZIP 청소하기
  이미 만들어둔 ZIP을 떨어뜨리면 안쪽 이름을 고쳐 다시 묶어줍니다.

Dock 아이콘에 바로 떨어뜨려도 동작합니다.


▷ 안전하게 만들었습니다

• 개인정보를 수집하지 않습니다. 네트워크 권한 자체가 없어서 macOS가 모든 연결을
  차단합니다.
• 여러분이 끌어다 놓은 파일 외에는 접근할 수 없습니다.
• 파일 내용은 읽지 않습니다. 이름만 고칩니다.
• Apple Silicon과 Intel 모두 네이티브로 동작합니다.


▷ 알아두면 좋은 것

이름 고치기는 APFS 볼륨에서만 유지됩니다. HFS+와 exFAT으로 포맷된 외장하드나
USB는 macOS 드라이버가 파일명을 자소분리 형태로 되돌려 씁니다. 그런 곳으로 옮길
거라면 이름을 고치는 대신 ZIP으로 묶으세요 — ZIP 안의 이름은 파일시스템과 무관하게
그대로 갑니다.

또 하나, 이름을 고쳐도 맥에서는 달라 보이지 않습니다. 원래 Finder에는 제대로
보이고 있었으니까요. 달라지는 건 파일이 맥을 떠난 다음입니다.


오픈소스입니다. https://github.com/clichedmoog/Moa
```

## 프로모션 텍스트 (170자 제한, 심사 없이 수정 가능)

```
맥에서 보낸 파일 이름이 윈도우에서 깨져 보인다면, 원인은 macOS가 한글 파일명을 풀어쓰기로 저장하기 때문입니다. 모아가 되돌려 줍니다. 윈도우에서 안 깨지는 ZIP도 만들어 줍니다.
```

## 남은 단계

계정 로그인이 필요해 자동화하지 못한 것들이다. 순서대로 하면 된다.

1. **스크린샷 올리기** — `docs/app-store/screenshots/` 의 PNG 3장을 버전 페이지의
   "앱 미리보기 및 스크린샷"에 끌어다 놓는다. (데스크탑 `Moa 스토어 자산` 폴더에도
   같은 파일이 있다.)
2. **연령 등급 설정** — 전부 "없음"이면 4+ 가 나온다.
3. **앱이 수집하는 개인정보** — "데이터를 수집하지 않음". 근거는 네트워크
   entitlement 자체가 없어 샌드박스가 모든 연결을 막는다는 것.
4. **가격 및 사용 가능 여부** — 무료, 전체 지역.
5. **빌드 업로드**

   ```bash
   # 앱 암호를 키체인에 한 번만 넣는다 (명령행에 노출되지 않게)
   security add-generic-password -a "tenma@mac.com" -s MOA_ASC_PASSWORD -w

   Scripts/release-mas.sh --upload
   ```

   처리에 10~30분 걸린다. 끝나면 버전 페이지에서 빌드를 고른다.
6. **심사에 추가 → 제출**
